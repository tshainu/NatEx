# Third-party browser OCR assets

These files are served from the NatEx website's own origin. No image or recognized text is sent to these projects or to a third-party OCR service.

- Tesseract.js 7.0.0 browser worker — Apache-2.0: https://github.com/naptha/tesseract.js/
- Tesseract.js Core 7.0.0 WebAssembly core — Apache-2.0: https://github.com/naptha/tesseract.js-core
- English trained data from `@tesseract.js-data/eng` 1.0.0 (`4.0.0_best_int/eng.traineddata.gz`) — MIT: https://www.npmjs.com/package/@tesseract.js-data/eng
- ZXing browser decoder `@zxing/browser` 0.2.1 — MIT: https://github.com/zxing-js/browser
- JsBarcode 3.12.3 — MIT: https://github.com/lindell/JsBarcode

The applicable Tesseract.js and core license texts and worker third-party license notice are included next to the assets. The English model is included for local browser use; see its package link above for the package license and source.
